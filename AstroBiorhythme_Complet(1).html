1. Points de départ des bio-rythmes (tours de 72°)

Comme dans le livre : on part du Soleil natal et on ajoute successivement 72° dans l’ordre zodiacal. Ces cinq points marquent le début de chaque « tour » ou bio-rythme.

2. Placement des planètes dans la grille 1-72

Distance angulaire (sens zodiacal) entre le Soleil et chaque planète. Le numéro du Génie-degré = position dans le cycle de 72° (1 = conjonction au Soleil, 37 = opposition dans le cycle réduit, etc.).

3. Aspectomètre réduit (cycle de 72°)

Dans le bio-rythme, les aspects classiques sont proportionnels : opposition = 36°, carré = 18°, trigone = 24°, sextile = 12°, demi-sextile = 6°, etc. Les Génies situés à ces distances d’une planète sont « sensibilisés ».
